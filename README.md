**SOLARA KEYS: HEATLINE** — an original 3D Three.js open-world coastal crime game running 100% offline in desktop Chrome. Explore 5 sunlit Miami/Keys-inspired districts (**Palm Strip**, **Coral Downtown**, **Marina Docks**, **Causeway Heights**, and **Ochre Yard**) on foot or by car as **Mateo Cruz**, steal and drift 7 vehicle classes amid autonomous traffic and pedestrians, battle rival syndicate crews with a 4-weapon arsenal, evade 5-star **SKPD** pursuits (cruisers, interceptors, tactical SWAT vans, roadblocks, and the **Air-One** searchlight helicopter), complete 6 story missions plus the Palm Strip Street Sprint, upgrade and respray at **Cruz Safehouse Garage**, tune 3 procedural Web Audio radio stations, and persist progress across 3 save slots.

## Run it

```sh
# Play locally in desktop Chrome (http://localhost:8080)
node serve.ts

# Build the competition dossier into out/
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
